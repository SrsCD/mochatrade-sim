# MochaTrade Growth Simulator

## Project Purpose
The **MochaTrade Growth Simulator** is an interactive decision-support tool that operationalizes BITREBELS' Round 1 trust-led, community-driven growth strategy into a quantitative first-year business model. 

It allows the growth team to dynamically adjust the acquisition channel mix, trust-building levers, retention curves, and pricing assumptions to instantly project the impact on activation rates, active traders, trading volume, and Year-1 fee revenue. The tool is designed to provide immediate reconciliation between a generic baseline and the strategic BITREBELS recommendation.

## Technology Stack
- **Frontend Framework:** Next.js (App Router)
- **Language:** TypeScript
- **UI & Styling:** React, Tailwind CSS v4
- **Data Visualization:** Recharts
- **Icons:** Material Symbols Outlined

## Setup Instructions
Ensure you have Node.js (v18+) and `npm` installed.

1. Clone or download this repository.
2. Open your terminal and navigate to the project directory.
3. Install the required dependencies:
   ```bash
   npm install
   ```

## Run Instructions
To launch the simulator locally for demonstration:

1. Start the development server:
   ```bash
   npm run dev
   ```
2. Open your web browser and navigate to `http://localhost:3000`.

Alternatively, to serve an optimized production build:
```bash
npm run build
npm start
```

## Model Overview
The simulator employs a deterministic, compounding month-over-month calculation model:
* **Activation Rate:** Scaled by both Trust Levers (up to 1.15x) and Acquisition Channel Effectiveness (e.g. Referral channels operate at 1.10x efficiency).
* **Active Traders:** Calculated via a compounding exponential decay loop where `Active_t = Activated_t + (Active_(t-1) × RetentionRate)`.
* **Trading Volume:** The aggregate flow generated by the pool of active traders at their average monthly volume.
* **Fee Revenue:** Derived purely from the calculated trading volume applied against the blended effective maker/taker fee rate.

## Assumptions Disclaimer
All conversion, retention, volume, and growth multipliers within the model are illustrative scenario inputs designed for internal hackathon simulation planning. They do not constitute forecasts of actual MochaTrade financial performance. Bybit's publicly listed non-VIP perpetual/futures fees are utilized as the external baseline pricing benchmark.
